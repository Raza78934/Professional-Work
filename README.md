# Azmat Raza Razvi — Website

A responsive, single-page personal portfolio with an emerald-green and gold Islamic-inspired visual identity.

## Files
- `index.html` — main page
- `assets/css/style.css` — layout, colors and responsive styling
- `assets/js/script.js` — mobile menu, theme toggle and footer year
- `assets/images/` — self-contained SVG artwork (no broken external image links)

## Publish on GitHub Pages from Android
1. Create or open the public repository `azmat-raza-razvi`.
2. Upload the **contents** of this ZIP so `index.html` is at the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for the deployment to finish and open the Pages URL.

## Customize
Replace the sample portfolio cards with links or screenshots of real projects. Check social links and contact details before publishing. Google Fonts requires an internet connection; the site otherwise includes its own artwork and does not rely on external image hosts.
